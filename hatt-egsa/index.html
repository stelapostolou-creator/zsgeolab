Οδηγίες

    
• HATT → ΕΓΣΑ87: διάλεξε φύλλο χάρτη.  ΕΓΣΑ87 → HATT: το φύλλο βρίσκεται αυτόματα.
• Δώσε συντεταγμένες για ένα σημείο, ή κάνε μαζική μετατροπή με επικόλληση / άνοιγμα αρχείου TXT/CSV.
• Οι επιπλέον στήλες που ανεβάζεις αγνοούνται στη μετατροπή αλλά παραμένουν στην εξαγωγή. Με τα τικ διαλέγεις αν θα κατέβουν όλες οι στήλες και αν θα υπάρχουν επικεφαλίδες.
• Προσοχή: στα άκρα των φύλλων χάρτη, η αυτόματη μετατροπή ΕΓΣΑ87 → HATT μπορεί να μη δουλέψει σωστά — σε τέτοια σημεία επιβεβαίωσε ή διάλεξε φύλλο χειροκίνητα.
