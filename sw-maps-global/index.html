Coordinate system

A declared CRS in a loaded file is picked up automatically and used as-is (no reprojection). With no CRS declared, data is read straight as WGS84 lat/lon unless you set one here.
Current: WGS84 (lat/lon)
This covers standard map-projection math for any EPSG code worldwide. It does not (yet) include your country's own official grid-based correction, where one exists and is needed for full accuracy. Want your country's exact transformation built in? Email supportlab@zstop.gr — happy to collaborate and add it.

Profile

Elevations and slopes along a line. You give the elevation at as many vertices as you want — the rest come from linear interpolation along the chainage, i.e. along the line, not in a straight line.
Slope between two vertices: the "from" vertex must already have a known elevation — it computes the "to" vertex's elevation from the slope. E.g. 1→15 by slope, then write the elevation of 30 directly — each segment interpolates on its own.

Offset

Area & surface

The volume comes from points that are already loaded — no other file needed. It does need a closed polygon though, to know which area to measure.
Takes only the points, not a ready triangulation — it's re-triangulated here, same logic as any other surface.
Builds a polygon from the outer points of the surface you picked, and shows it on the map. Empty tightness = convex hull, never fails. With tightness (try 2 to 3) it follows shapes like a Γ — but on irregular points it can fragment, and it will tell you.

Compute

Advanced: triangle edge limit
The area is defined by the polygon, and anything outside it isn't measured — so normally nothing is needed here. Only needed when the polygon is larger than the survey, e.g. a parcel that was only partly measured: then triangles with a larger edge are treated as unmeasured.

Export DXF

Contours and digital terrain model in the active CRS, for each surface you selected. Contours come straight from the triangles, so they pass exactly through the measured elevations — no smoothing.
Each surface is exported to its own file — layers are always fixed English names (POINTS, DTM, CONTOURS, CONTOURS_INDEX, BOUNDARY), not the surface's own name, so non-English names can't break the DXF.
